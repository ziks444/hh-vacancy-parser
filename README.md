# 🕷️ HH.ru Vacancy Parser — сбор и анализ вакансий с hh.ru

Инструмент на Python для сбора и анализа актуальных вакансий с сайта hh.ru по любому поисковому запросу. Парсер собирает вакансии через **Selenium**, сохраняет сырые данные в JSON, нормализует их (зарплаты в рублях за месяц, «на руки» / «до вычета налогов», дата публикации, город), загружает в **PostgreSQL** и строит Excel-отчёт с графиками.

```
hh.ru ──Selenium──▶ data/raw/*.json ──load.py──▶ PostgreSQL (vacancies, skills, vacancy_skills)
                          │
                          └──parser.py──▶ Excel-отчёт
```

Проект разработан в рамках учебной практики по анализу рынка труда IT-специалистов.

## 📊 Функциональность

- ✅ Сбор всех вакансий по запросу и региону — без фильтра по названию и без отбрасывания «неполных» вакансий
- ✅ Сохранение сырых данных каждого сбора в JSON (`data/raw/`) — отчёт можно перестроить без повторного сбора
- ✅ Извлечение полей: название, работодатель, зарплата, тип оплаты, опыт, занятость, график, рабочие часы, формат работы, навыки, адрес, дата публикации
- ✅ Конвертация валют (USD, EUR → RUB) и приведение зарплат к месячному эквиваленту (часовые, дневные, недельные ставки)
- ✅ Загрузка в PostgreSQL без дублей (upsert по ID вакансии), навыки — отдельный справочник со связью «многие ко многим»
- ✅ Excel-отчёт с 6 листами и 4 типами графиков
- ✅ Модульная структура и тесты (pytest)

## 🛠️ Технологии

- **Python 3.10+**
- **Selenium** — управление браузером Chrome, работа с динамическим контентом
- **pandas** — обработка и структурирование данных
- **xlsxwriter** — Excel-файлы с форматированием и встроенными графиками
- **matplotlib** — графики и диаграммы
- **PostgreSQL 17** + **psycopg 3** — хранение данных
- **pytest** — тесты

## 📥 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ziks444/hh-vacancy-parser.git
cd hh-vacancy-parser
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Убедитесь, что установлен **Google Chrome** (Selenium 4.6+ сам скачивает ChromeDriver при первом запуске)

## 🚀 Запуск

```bash
python parser.py
```

Параметры можно задать при запуске:

```bash
# Другой запрос, 3 страницы поиска, не больше 100 вакансий
python parser.py --query "аналитик данных" --pages 3 --max 100

# Построить отчёт по уже сохранённому сбору, не открывая браузер
python parser.py --from-raw data/raw/vacancies_2026-10-30_1946.json --output report.xlsx
```

Парсер:
1. Откроет браузер Chrome и пройдёт по страницам поиска hh.ru
2. Соберёт ссылки на все вакансии и запарсит каждую
3. Сохранит сырые данные в `data/raw/vacancies_<дата>_<время>.json` — даже если сбор прервать через Ctrl+C
4. Нормализует данные и сохранит отчёт в `vacancies_moscow.xlsx`

Между запросами выдерживается пауза (`REQUEST_DELAY` в `config.py`), чтобы не создавать лишней нагрузки на hh.ru.

## 🐘 Загрузка в PostgreSQL

1. Создайте пользователя `hh_app` и базу `hh_vacancies` (один раз, под суперпользователем `postgres`; пароль `hh_app` спросит psql):
```bash
psql -U postgres -h localhost -f sql/00_create_database.sql
```

2. Скопируйте `.env.example` в `.env` и впишите пароль `hh_app` в `PGPASSWORD` (файл `.env` не хранится в git).

3. Загрузите собранные данные:
```bash
# все файлы из data/raw
python load.py

# или конкретный сбор
python load.py data/raw/vacancies_2026-10-30_1946.json
```

Скрипт сам создаёт таблицы из `sql/schema.sql`. Повторная загрузка не создаёт дублей: вакансия обновляется по ID, а поля `first_seen_at` / `last_seen_at` показывают, когда вакансия впервые и в последний раз попала в сбор.

### Схема базы

| Таблица | Что хранит |
|---|---|
| `vacancies` | вакансия: работодатель, город, опыт, занятость, формат работы, зарплата в рублях/мес (от, до, среднее), исходная валюта и период, «на руки» / «до вычета», дата публикации, поисковый запрос, первое и последнее появление в сборе |
| `skills` | справочник навыков (уникальные названия) |
| `vacancy_skills` | связь вакансий и навыков («многие ко многим») |

## 📊 Отчёт

Excel-файл содержит 6 листов:

1. **Вакансии** — все собранные вакансии с нормализованными полями
2. **Статистика по зарплате** — средняя, медиана, мин/макс по вакансиям с указанной зарплатой + гистограмма
3. **Обязательные навыки** — топ-15 навыков + горизонтальная диаграмма
4. **Требования к опыту** — распределение по опыту + столбчатая диаграмма
5. **Тип занятости** — круговая диаграмма
6. **Описание результатов** — сводка: сколько вакансий собрано и у скольких указана зарплата, зарплаты, топ-5 навыков, опыт, валюты

## ⚙️ Как устроена обработка

### Зарплата

Парсер распознаёт:
- **Период**: за час, день, смену, неделю, месяц, проект
- **Валюту**: RUB, USD, EUR (по символам `$`, `€`, `₽` и текстовым маркерам)
- **Тип оплаты**: «на руки» или «до вычета налогов»
- **Конвертация**: 1 USD = 95 RUB, 1 EUR = 103 RUB
- **Приведение к месячному**: часовая × 168, дневная и сменная × 22, недельная × 4.3

**Пример**: `"от 5 000 $ за месяц"` → 5000 × 95 = **475 000 руб./мес.**

### Остальные поля

- Подписи полей убираются: «График: 5/2» → «5/2», «Тип занятости Полная занятость» → «Полная занятость»
- Дата публикации: «Вакансия опубликована 23 октября 2026» → `2026-10-23`
- Город берётся из адреса вакансии

## 🔧 Настройка

Параметры по умолчанию задаются в `config.py`:

```python
QUERY = "Python Developer"   # поисковый запрос
AREA_ID = 1                  # регион hh.ru (1 — Москва)
PAGES = 5                    # сколько страниц поиска пройти
MAX_VACANCIES = 200          # максимум вакансий за запуск
REQUEST_DELAY = 1.0          # пауза между запросами, сек

USD_TO_RUB = 95.0
EUR_TO_RUB = 103.0
```
